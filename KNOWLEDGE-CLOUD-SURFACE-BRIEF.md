# Opt-in cloud Q&A extension

Mode: Operate. User selected cloud processing through the project's existing service. Extend knowledge Q&A only; no layout replacement, model/key entry in renderer, media upload, OCR, semantic retrieval or team sharing.

## Direction contract

THESIS: Choose original excerpts or explicitly send a bounded set of personal evidence for synthesis; never confuse AI wording with source text.

OWN-WORLD: Preserve the dark sidebar, white workspace, Chinese system type, green primary action, existing borders, muted help and error strip.

STORY: Original excerpts remain default. The cloud checkbox explains provider, disclosure and potential costs before submission. Missing configuration disables it. Errors retain the question and offer original excerpts without a hidden paid retry.

FIRST VIEWPORT: Existing heading, explanation and question row stay in place. A labeled opt-in checkbox and one explanatory paragraph precede the question. Results distinguish AI synthesis from excerpts and retain numbered source buttons.

FORM: Code-led narrow extension; no seed or concept tournament, raster asset or new motion. Signature interaction is an explicit, reversible mode choice with a different action and result label.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Ordinary extension: preserve incumbent system files; document evidence rather than invent a global DESIGN.md. Development-only, not bundled.
