本分支将知识库基线与健康管理商业情报频道的 R3 修复整理为可运行源码。Git 基线为远端 0.6.0（`fd7462f`），分支为 `codex/r3-health-sync-20261104`。完整文件散列见根目录 `SOURCE-MANIFEST.json` 和 `SHA256SUMS.txt`；当前测试汇总见 [测试结果](r3-git-sync-20261104-tests.json)。

## 范围与行为

- 健康频道使用 canonical `health`，兼容 `demo-health`，保留原文章与个人阅读、收藏状态；旧客户端配置不会覆盖服务端托管规则。
- 健康采集、08:15准备/09:00投递、ACK去重、受限迁移/回退与真实定时验收脚本齐备，部署说明见 [健康采集说明](../../server/HEALTH_COLLECTOR.md)。
- 桌面挂件存活时，关闭主窗口会最小化以保留同一renderer和后台消息处理；明确退出、无挂件或挂件已销毁时正常关闭。
- 正式本地工程只受控更新55项；12项后续不同内容和其余原文件、暂存区、HEAD保持。内部管理系统入口与并行PaddleOCR等工作区独有修改没有夹带进这个分支。

## 运行与检查

使用 Node.js 22 和 Python 3.12。桌面端在仓库根目录执行：

```powershell
npm ci
npm run dev
```

源码验证：

```powershell
npm run build
npm run test:desktop
npm run test:knowledge-desktop
node scripts/test-health-window-lifecycle.cjs
node scripts/test-health-stream-status.cjs
```

后端在独立Python虚拟环境安装 `server/requirements.txt`，按 `server/.env.example` 设置独立数据库、私有文件目录和API密钥，执行既有 Alembic 迁移后，在 `server/` 中运行 `python -m uvicorn app.main:app --host 127.0.0.1 --port 19080`。原生SILK可选依赖见 `server/requirements-silk.txt`。测试需安装pytest，使用独立SQLite/test-key，清除远程数据库与云密钥变量后执行 `python -m pytest server/tests`。不要把生产配置或个人profile放入Git。

Windows安装包使用 `npm run dist:win`，生成到工程 `release/`；本次Git同步没有发布安装包或标签。
