## 缺陷与复测

- 复制成员档案可能保留上一成员的称呼提示：新身份开始引导时清除专属提示块；复制隔离用例和原生克隆场景通过。
- 损坏的引导状态不能静默重置：保留记录并返回中文错误；边界复测通过。
- 把工具命令或授权指令当作昵称：拒绝指令式称呼；权限配置字节不变的用例通过。
- 旧称呼插件只能依赖已经存在的模块别名，新原生进程加载失败：先复现红测，再改用当前原生平台模块并保留旧版回退；3 项称呼测试、真实适配器注册、正式 default 克隆及热加载通过。
- 测试工具初次把原生创建的空 pairing 目录当成连接泄漏：修正为检查真实文件和原生渠道配置；未放宽连接或凭据约束。隔离文件清理权限问题也在工具层修正，最终进程退出码为 0。

首轮与修复后日志均保存在本机证据目录；legacy test_router.py 的历史全量测试不在本次新增通过声明内，本次运行的是其现有独立任务新增回归组。
