# 迈医协同 0.6.9 发布记录

范围：按用户 2026-11-23 最新要求，将 SignalDesk 工程当前全部待发布改动一并发布，包含管理员直接代成员开通、取消频道订阅，并更新正式后台、本机 Windows 客户端、自动更新源和 Git。患者端、医疗管理系统为独立工程，不在本次范围。

使用入口：**用户管理 → 所选成员的“管理” → 频道订阅 → 勾选或取消频道 → 保存频道订阅**。管理员保存直接生效，成员无需再次订阅。该入口与“智能频道 → 订阅权限”分工不同：前者保存实际订阅，后者决定谁有资格订阅。无有效微信、成员停用、无频道页面权限、频道暂停或未开放订阅资格时，新增订阅显示原因；已有订阅可取消。

验收条件：管理员开通和取消后成员目录立即体现，其他成员不变；普通成员、匿名和服务密钥不能代订阅；旧表单与微信换绑冲突不会覆盖新结果；更新保留既有订阅、微信绑定及视频运行环境；同事客户端能从正式更新源自动检测下载新版。

源码主入口仍为 `D:/maiyi/SignalDesk`。前端执行 `npm run typecheck`、`npm run build:web`，输出 `dist/`；后台沿用 `server/README.md` 的启动配置。安装包输出 `release/admin-member-subscriptions-v0.6.9/`，证据目录 `artifacts/admin-member-subscriptions-v0.6.9/`。复用既有 Electron、React、FastAPI 和测试工程，不增加依赖或数据库迁移。

本版 Git 同步还包括已部署的微信扫码绑定、按档案路由推送、自然语言第一人称任务入口以及对应测试和操作脚本。发布差异逐文件冻结，不以本机旧 main 的未提交列表判定是否已在正式环境运行。Hermes 8 个档案的共享任务插件已逐文件核对，与本版源码一致。
